# Auxillery

**Auxillery** is a collection of modular utility libraries designed to support Roblox game development. Many modules are standalone and focus on staying versatile and useful.

## Features

- Lightweight and modular  
- Roblox-specific utilities
- Easy to integrate and extend  

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/fire1sky/Auxillery.git
   ```
2. Copy the [`Auxillery`](./src/Auxillery.lua) Module and paste it into your roblox game.
3. Make a Components folder inside the Auxillery Module, and paste everything in from [`here`](./src/Components).
